# Changelog

## 0.1.0 Beta — 2026-07-30

- Added Flat, Perspective, and Realistic Cast shadow modes
- Added linked source/shadow management and post-transform updates
- Added direction, length, perspective, skew, feather, fade, opacity, and color controls
- Added light-size and contact-softness controls for progressive penumbra
- Added all 27 Photoshop blend modes with Normal as the default
- Added Natural, Graphic, and Dramatic Quick Start presets
- Added Photoshop's native color picker
- Added dark and light Photoshop theme support
- Added compact responsive panel layout
- Added distributable `.ccx` package
